# TaskFlow

O **TaskFlow** é um projeto full stack desenvolvido para facilitar a organização e o acompanhamento de tarefas em equipe.  
A aplicação integra uma **API REST em Java Spring Boot**, com banco de dados **H2**, a interfaces **Angular** e **Expo (React Native)**.  
Na versão web, é possível **cadastrar, consultar, editar, excluir e filtrar tarefas** de maneira simples e prática.  
No aplicativo mobile, os usuários podem **visualizar os detalhes das tarefas e atualizar seus status**, usando a mesma API.  
O projeto valoriza a **integração entre plataformas, o trabalho em equipe e as boas práticas de versionamento com GitHub**.

## ⏱️ Cronograma de Desenvolvimento — 210 minutos

O hackathon terá duração total de **3 horas e 30 minutos**, dividido em etapas de organização, desenvolvimento, integração, testes e apresentação.

| 🕒 Período | 📝 Atividade | ⏳ Duração |
|:---:|---|:---:|
| 00:00 – 00:20 | Organização, configuração do GitHub, criação do Board e divisão de tarefas | 20 min |
| 00:20 – 00:55 | Implementação inicial da API | 35 min |
| 00:55 – 01:45 | Desenvolvimento paralelo com Angular e Expo | 50 min |
| 01:45 – 02:30 | Integração das tecnologias, ajustes e Pull Requests | 45 min |
| 02:30 – 03:05 | Testes, correções, merges e documentação (README) | 35 min |
| 03:05 – 03:30 | Apresentação e avaliação dos projetos | 25 min |

**📌 Observações:**
- As atividades de desenvolvimento poderão ocorrer em paralelo, conforme a divisão de responsabilidades da equipe.
- Cada equipe terá aproximadamente **3 a 4 minutos** para apresentar seu projeto, dependendo da quantidade de grupos participantes.

## 📊 Critérios de Avaliação — Nota Máxima: 10,0 pontos

A avaliação considerará tanto o desenvolvimento individual das tecnologias quanto a integração entre elas, a organização do trabalho e a capacidade de demonstrar o funcionamento da aplicação.

### 🏆 Distribuição de Pontos

| Critério | Pontuação | O que será avaliado |
|---|:---:|---|
| **Backend — Java Spring Boot** | 2,0 | API REST, banco de dados H2, organização em camadas, validações e funcionamento dos endpoints. |
| **Frontend — Angular** | 1,5 | Implementação de CRUD, componentes, formulários e consumo da API. |
| **Aplicativo — Expo** | 1,5 | Listagem de dados, visualização de detalhes, atualização de status e comunicação com a API. |
| **Integração das três tecnologias** | 1,5 | Fluxo completo de comunicação: Angular → Java → Expo → Java → Angular. |
| **GitHub — Branches e Pull Requests** | 1,5 | Organização das branches, revisão de PRs, commits padronizados e colaboração entre integrantes. |
| **GitHub Projects** | 1,0 | Organização do Board, criação de tarefas, atribuição de responsáveis e movimentação das atividades. |
| **README e apresentação** | 1,0 | Documentação com instruções reproduzíveis, demonstração do projeto e clareza na explicação. |
| **TOTAL** | **10,0** | |

### 📋 Regras de Correção

A avaliação seguirá as seguintes regras:

1. **Demonstração dos requisitos:** serão atribuídos pontos proporcionais aos requisitos efetivamente implementados e demonstrados.

2. **Integração com a API:** interfaces que não possuírem integração real com a API não receberão pontuação integral nos critérios correspondentes.

3. **Histórico de desenvolvimento:** o histórico de commits, Pull Requests e Issues poderá ser utilizado para verificar a participação e as contribuições de cada integrante.

4. **Conhecimento do projeto:** todos os integrantes deverão ser capazes de explicar sua participação e o funcionamento geral da aplicação.

5. **Avaliação individual:** a nota do grupo poderá sofrer ajustes individuais, devidamente fundamentados na participação e no desempenho durante a apresentação.

6. **Uso de inteligência artificial:** ferramentas de IA poderão ser utilizadas como apoio ao desenvolvimento. Entretanto, os alunos deverão compreender, testar e saber explicar o código produzido.

---

**💡 Importante:** a pontuação será baseada no funcionamento real da aplicação, na integração entre as tecnologias e na participação efetiva dos integrantes durante o desenvolvimento.
